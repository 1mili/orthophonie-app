## 🌟 Overview
An advanced graduation project (PFE) designed to bridge the gap between parents and speech therapists. The platform streamlines clinical workflows, offers interactive remote sessions, and provides dedicated dashboards tailored for each user role.

## 🚀 Key Features
* 🩺 **Teleconsultation:** Real-time video communication capabilities using WebRTC.
* 🎮 **Medical Games Marketplace:** Interactive tools and therapeutic games to assist speech therapy sessions.
* 📊 **Multi-Role Dashboards:** Dedicated, secure interfaces for Parents, Therapists, and Administrators.
* 📝 **Blogs & Service Directories:** Integrated articles and professional directories for easy client discovery.
* 🔒 **Secure Authentication:** JWT authentication stored securely in httpOnly cookies alongside bcryptjs password hashing.

## 💻 Tech Stack
* **Frontend:** Next.js, React, Tailwind CSS (Strict TypeScript architecture)
* **Backend:** Node.js, Express
* **Database & ORM:** PostgreSQL hosted on Supabase, managed via Drizzle ORM
* **Payments & Real-time:** Stripe for online payment processing, WebRTC for video streaming
* **DevOps & Tools:** Docker, Vercel, VS Code, Ubuntu
